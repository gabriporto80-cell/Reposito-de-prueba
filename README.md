# Portal de vivienda pública - Peitos React

## Qué es el proyecto
Aplicación de portada para un portal de vivienda pública, hecha con React y Vite, usando un servidor JSON local.

## Cómo se instala
Clona el repositorio y ejecuta:
- `npm install`

## Cómo se arranca
En una terminal:
- `npm run dev` para la portada (`http://localhost:5173`)
En otra terminal:
- `npm start` para `json-server` con `db.json` (`http://localhost:3001`)
